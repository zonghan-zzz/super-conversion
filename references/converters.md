# 转化器：先设计值得行动的理由，再设计入口

2026-10-12 根据用户反馈整理。“转化器”指连接页面内容与下一步行为的完整入口：可见形式、承诺的权益、必要证据与条件、点击后的动作及反馈。按钮只是其中一种形式。此为本 skill 的应用方法，不是陈勇或福格原书中的新公式。

## CV-01｜让理论决定设计

每个主要转化器先写清：目标人群与当前意图 → 想获得什么 → 犹豫或阻碍 → 对应 CY/FM 机制 → 具体权益与证明 → 下一步与兑现 → 验证指标。再构思至少两种适合该场景的入口形式，比较注意力成本、点击动机、操作负担、可信度及与页面内容的关系，选择最有说服力的一种。不能先画大按钮，再贴理论标签。

陈勇的三步用于检查兴趣、信任和行动理由；福格 MAP 检查同一时刻是否值得做、容易做、被有效提示。用具体页面证据连接两者，不能简化为“福格负责表单，六要素负责装饰”。

## CV-02｜获取感：把权益做实、做具体、做可感知

- 先确定能交付的内容、适合的人、领取条件与交付时机，再写“领取”。“获取方案”没有说明方案内容时，仍是抽象动作。
- 将真实权益预览放在行动附近，例如案例目录、可读样页、可体验的功能、可选择的真实模板。让人能判断价值；封面、礼盒和大数字不能代替内容。
- 使用“领取＋具体所得”的候选文案，并考虑用户的任务，例如领取同行案例、保存所选模板、体验会员运营。奖励应与高质量需求相关，避免只吸引与产品无关的领取者。
- “免费”“专属”“已为你生成”“价值某金额”必须有对应事实。拟议资料包明确标为待业务落实，不能画成已生成或已发放。

## CV-03｜损失框架：说明真实机会成本

损失厌恶涉及相对参照点的得失评价，来自前景理论等行为研究，不属于福格模型或六要素的同义词。参照点可能是已拥有的客户、已投入的获客成本或已安排的活动；先说明参照点，再提出损失框架假设。

有依据时可表达“客户买过一次后，如何继续连接？”等经营问题，并紧接具体解决方式。场景问题不等于已证实用户正在损失。不要编造每日损失金额、确定流失率、夸大竞品领先或用羞辱式退出文案；不得假称权益已归用户所有、关闭即永久失去。没有损失证据时优先采用正向收益或可核查的自测问题。

## CV-04｜从众、紧迫性与稀缺分别设计

| 机制 | 优先材料与应用 | 不可混淆之处 |
|---|---|---|
| 从众 / CY-05 | 同行业、同规模、同任务的真实案例与评价；把场景及来源放在领取附近 | 品牌logo不是用户好评；注册商家数不是当前领取人数；公开案例不是普遍收益 |
| 时机 / FM-04 | 真实活动准备节点、任务即将开始、用户已选定的目标；说明此刻做的实际帮助 | “今天开始”是建议；7天试用是使用时长，不是7天后停止报名 |
| 稀缺 / CY-07 | 已确认的活动截止、服务容量或明确资格；展示范围、时区、条件与真实余量 | 普通数字资料、可无限复制的软件不是自然限量；没有容量数据不用剩余名额 |

有真实业务约束时主动把它设计清楚；缺材料时可以提出可执行的活动方案（资源/负责人/容量依据/开始截止/交付/计数更新/售罄状态），标记为待确认方案，正式主稿不写虚构人数、金额、倒计时或实时动态。真实“限时/限量/限资格”可提供行动理由；不要求每个转化器都叠加这些机制。

“刚刚有人领取”“某行业刚刚领取”可以作为底部悬浮广告、案例区边栏或领取层中的动态信号候选，但必须先定义领取成功事件、去重口径、显示时间窗口、行业归属来源、刷新延迟和无数据时的退化文案；不得用随机姓名、循环播报或假计数伪装实时。倒计时要绑定已确认的截止时间和时区，结束后有明确状态；试用时长不能冒充领取截止。概念图可在说明中标注“需真实数据接入”的候选态，不能把占位数字画成已经发生的事实。

## CV-05｜按场景创造转化器，不套按钮模板

先保证“一眼知道能得到什么、对我有什么用、为何可信、点击后做什么”，再比较入口形式。以下是创意候选库，不是每页必放清单：

| 页面场景与意图 | 可比较的形式 | 选择依据 |
|---|---|---|
| 首屏首次了解 | 明确利益的主按钮、可操作的方案选择器、带内容预览的领取卡 | 能否在短时间内理解价值和下一步；首屏只突出一个主行动 |
| 案例或行业内容 | 可翻看的案例样页、同行场景标签、进入案例详情的整卡入口、轻量文字链 | 用户想先判断相关性时，预览与证据通常比催促留资更贴近任务 |
| 工具或解决方案区 | 体验卡、可选模板、简短诊断、任务型按钮 | 点击后能立即体验或看到与选择相关的结果 |
| 权益与活动区 | 优惠券、红包、领取票据、限时活动卡 | 真实可兑现的所得与资格清楚；装饰性奖励不能替代实际价值 |
| 长页面回访决策点 | 底部悬浮广告、收起式权益条、就近的上下文入口 | 用户滚动到相关证据后可方便继续；悬浮层不能遮挡阅读和系统操作 |
| 次要解释或细节 | 文字链、展开、整卡导航，或不设入口 | 避免每张小卡都争抢主行动的注意力 |

大板块在用户完成一个判断的节点设置醒目且易点的转化器，小卡片按内容和主次采用文字链、按钮、整卡入口或不设动作。逐个场景说明“为什么这种形式比另外的候选更适合”，并写出点击后去向与领取/失败/返回状态。底部悬浮广告需有关闭或收起方式、移动端安全区域和遮挡检查；滚动中不要反复抢焦点。同一视野保持清晰主行动，避免全页机械重复孤立大按钮，也避免为了变化堆砌多套礼包、横幅和动效。统一品牌、字体与间距，必要条件不能因追求简洁而隐藏。

## CV-06｜完整而简洁：内容对照与渐进展示

1. 生成前建立原内容清单：能力及子项、案例及行业、服务、证据、权益条件、下一步、法律与帮助入口。记录每项改后位置和状态：保留、合并、移至详情、待核实。不得无记录地删除。
2. 从目标用户的主要问题重新组织叙事，不被原区块顺序绑住。首屏选一个有吸引力且可验证的核心主张，配一份最相关的证据或预览和一个清楚的主行动；据流量来源、用户认知和业务约束选择文案、布局或交互创意，避免把所有利益、数字和活动贴在第一屏。检验用户能否很快说出“这是给谁的、解决什么、下一步能得到什么”。
3. 后续按用户的决策顺序重组内容，例如适配性 → 方案能力 → 同行证据 → 实施与条件 → 行动。可重写标题、合并重复说明、调换板块、统一比较方式，使用短标题、分组和留白。低频细节可进入明确的标签页、展开区或详情，但不能把必要条件藏起来。原内容唯一信息没有去处即算遗漏。
4. 静态图中的折叠和标签页不是已实现内容。用户要求完整页面时，同时给出内容映射；被折叠的重要内容提供对应展开态或明细，不能只画一个“更多”就宣称完整。
5. 用户指定某版为基线时使用该确切文件作为事实与内容的基线；如同时要求重设计，则在授权范围内改变表达和结构。AI 生图后按清单复查，不用“更简洁”解释误删。

## CV-07｜验证兴趣与最终收益

检查用户能否说清权益和下一步；跟踪转化器曝光 → 点击 → 手机验证/目标完成 → 实际交付 → 有效使用及线索质量。理论只能支持待验证假设，不代表确定提升。必要时在同一权益下对比收益框架与损失框架；活动稀缺须有真实资源约束，不能为了实验造假。
