# 超级转化 · Super Conversion

基于陈勇《超级转化率》、福格行为模型与行为设计方法，诊断页面和转化流程，先分析、再给建议、最后生成优化后的 UI 效果图。个人经验仅作参考，改版效果需要实际验证。

仓库地址：https://github.com/zonghan-zzz/super-conversion

## 使用

将整个仓库作为 `super-conversion` 文件夹安装到支持本地 Skills 的工具中。Codex 可放入 `~/.agents/skills/super-conversion/`。

提供页面链接、Figma 链接或截图，以及转化目标，例如：

> 请调用 $super-conversion 分析这个页面，目标是获取客户手机号。先检查福格模型和转化六要素，再提出改进建议，最后生成 PC 和 H5 的 UI 效果图。

生图、网页浏览和 Figma 读取依赖使用环境提供的相应工具及权限。本仓库不包含账号、API 密钥或工具服务。

## 内容

- `SKILL.md`：入口、执行流程和交付要求。
- `references/`：转化六要素、福格模型、行为设计、页面工作流、手机号留资、个人经验与来源。
- `agents/openai.yaml`：显示名称与默认调用提示。

## 更新

本仓库是该 skill 的版本维护入口。后续更新提交并推送至同一个远程仓库，不为每次改动新建仓库。通过 Git 安装的使用者可在本地无未提交修改时执行 `git pull --ff-only` 获取更新。

方法论内容为摘要与应用推导，不包含原书全文；理论、个人经验与实验结论应明确区分。
